# Чтение глазами: порядок работы агента

Тебе дали список страниц, которые локальный OCR не прочитал (петля, обрыв, рукопись, плохое фото). Прочитай каждую по картинке и запиши расшифровку. Больше ничего: OCR не запускать, `.md`, `_ocr.json` и исходники не трогать.

В задании должны быть: `<папка навыка>` (каталог `SKILL.md`), исходный файл, номера страниц, поворот каждой страницы (`rotation` из `_ocr.json`) и папка `.md` документа. Это служебная рабочая папка `<папка запуска>/documents/…`, а не пользовательская папка результата.

## Для каждой страницы

1. Сделать картинку скриптом во временную папку (в Claude Code — scratchpad сессии, в ChatGPT/Codex — `<папка запуска>/tmp`) и открыть её инструментом просмотра локальных изображений (в Claude Code — Read, в ChatGPT/Codex — `view_image`):
   `~/ocr-env2/bin/python -I "<папка навыка>/scripts/render_page.py" "<исходник>" <стр> <поворот> "<временная папка>/p.png"`
   Поворот — из задания. У одиночного фото номер страницы 1; у многостраничного TIFF — номер кадра. Если текст всё равно лежит боком, повторить с поворотом +90.
2. Если мелкий шрифт или почерк не разобрать, повторить с dpi 300 (пятый аргумент) и открыть верхнюю и нижнюю половины отдельно (обрезать через PIL). Больше трёх картинок на страницу не открывать.
3. Записать `<папка .md>/_ЧТЕНИЕ-<имя .md без расширения>-стр-N.md`. Имя строго такое: потом `merge_eyes.py` вставит файл в `.md` вместо OCR-текста страницы, а страница заменяется целиком. Одна страница — один файл:
   - первая строка: `# Чтение глазами: <исходный файл>, стр. N`;
   - рукописное и всё существенное — дословно, с орфографией оригинала. Печатный бланк можно сократить до сути, но только явной пометкой: `[печатный бланк сокращён: объяснение, графы …]`;
   - неуверенное слово — `слово[?]`, неразборчивое — `[неразборчиво]`, за краем кадра — `[…]`;
   - зачёркнутое — `~~текст~~` (зачёркнутое назначение означает отмену, это важно); если под зачёркиванием не прочесть — `[зачёркнуто: неразборчиво]`. Пометки вроде «отм», «отменено» — как написаны, не расшифровывать по догадке;
   - подпись — `[подпись]`; росчерк не превращать в буквы или цифры;
   - таблица — таблицей Markdown с теми же строками и столбцами; рукописное значение — в своей ячейке. Отметки в сетке по часам (X, галочки) — в своих столбцах;
   - ничего не додумывать: фамилии, даты, суммы, номера — только как видно на картинке.
4. После записи проверить реквизиты в каждом записанном файле отдельно: `python3 "<папка навыка>/scripts/requisites.py" "<папка .md>/_ЧТЕНИЕ-<имя .md без расширения>-стр-N.md"`. По папке скрипт пропускает файлы, имя которых начинается с `_`, и ничего не найдёт. Если реквизит на прочитанной странице не сходится (контрольная сумма ИНН/ОГРН/счёта, сумма прописью не равна сумме цифрами), посмотреть эти цифры по картинке ещё раз (dpi 300, нужный кусок страницы). То, что не сошлось и после этого, оставить как видно, с `[?]`: подгонять цифры под контрольную сумму нельзя. Оставшееся расхождение назвать в отчёте.

## Чего не делать (ошибки прошлых прогонов)

- **Не подставлять правдоподобное слово вместо неразборчивого.** Вывеску «Рассвет» записали как «Радуга» без `[?]`, фамилию «Кра…ов» — как «Крапивов». Если слово видно не целиком, писать видимые буквы и `[?]`: `Кра[неразборчиво]ов[?]`. Обычное слово с уверенным видом хуже честного пропуска.
- **Не переносить сведения с других страниц и файлов.** Инициалы «Т.В.» из соседнего документа попали в протокол, где на картинке «Н.В.». Чего нет на этой странице, того нет в расшифровке. Если очень нужно, отдельной строкой в конце: `[для сверки: на стр. N написано …]`.
- **Не «исправлять» цифры по смыслу или по аналогии.** Телефоны, ИНН, ОГРН, счета, паспорта — цифра за цифрой, как видно; сомнительная цифра — `[?]` сразу после числа. Повторный снимок того же листа не заменяет чтение этой страницы: читать свою картинку, а расхождение со снимком указать строкой `[для сверки: …]`.
- Фамилия, имя, название организации или магазина, в которых не уверена хоть одна буква, — всегда с `[?]`.
- **Не пересказывать.** Списки препаратов, назначения, дозы, показатели анализов — дословно, каждая позиция с дозой и кратностью. Пересказ «перечень препаратов содержит: …» уже стоил всех дозировок страницы. Сокращать можно только печатный бланк и только явной пометкой (п. 3).

## Что вернуть (не длиннее 10 строк)

Список записанных файлов; страницы, где больше пяти `[?]` и `[неразборчиво]`; реквизиты, которые не сошлись после повторного взгляда (страница, число); страницы, которые не удалось открыть, и почему. Текст расшифровок не пересказывать.
